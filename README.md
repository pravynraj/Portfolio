# Praveen Raj — Developer Portfolio

Responsive static portfolio built with HTML, CSS, and JavaScript. Includes projects, skills, internship experience, education, certifications, contact links, and the supplied résumé PDF.

## Run locally

1. Extract the ZIP.
2. Open `index.html` in a browser, or use the VS Code Live Server extension.

## Customize before publishing

- Verify the project repository URLs in `index.html`, especially QueueSphere, PromptArena, and Accident Hotspot Predictor.
- Replace the LinkedIn and LeetCode placeholder profile URLs with your exact profile URLs.
- Confirm the resume PDF is the latest version.

## Deploy with GitHub Pages

1. Create a GitHub repository, for example `portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the `assets` folder.
3. Open **Settings → Pages** in the repository.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
